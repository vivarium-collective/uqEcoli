Quick Start

Run the UQ pipeline on your own data:
# Install
pip install uqecoli
# Stage 1 — sample + evaluate
uv run uq sample /path/to/simData.cPickle --n-samples 20 --live
# Stage 2 — quantify
uv run uq quantify experiment_id --sim-base-path /path/to/sims --precomputed-path ./uq_cache
# Generate report
uv run uq report --results-path ./uq_results
