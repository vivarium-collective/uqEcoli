uq CLI Reference

All 13 subcommands of the scientifically transparent UQ for vEcoli CLI

Workflow Commands

CommandStageDescription
sample P1 Steps 1-3 Generate LHS parameter samples via PCRV germ sampling, run vEcoli simulations (local subprocess or SMS-API remote), cache results. Core inputs: simData path, n_samples, observables.
quantify P1 Steps 4-5 Fit PCE surrogates (PyTUQ), compute Sobol indices across all 4 RFC006 aggregation strategies. Auto-generates report.html. Supports held-out validation (--n-test).
report Output Generate a self-contained HTML report from UQ results directory. Interactive PCE explorer with client-side JS Legendre evaluation. Works standalone from cached results.

Interactive & Visualization

CommandTypeDescription
dashboard GUI/Tk Launch the UQ interactive dashboard (tkinter DAW by default). Loads uq_results.json + surrogate binaries for PCE response curves, observable waveform, sensitivity spectrogram.
tui TUI Launch the UQPC interactive terminal UI (Textual framework). Parameter importance table, observable selector, live mode with periodic refresh.
gui GUI Launch the UQPC interactive GUI (marimo). Reactive parameter sliders, response curves, multi-parameter drag interaction. Runs as a marimo notebook.

Analysis & Comparison

CommandTypeDescription
compare Analysis Side-by-side Sobol comparison across multiple UQ experiments. Rank stability indicators, universal vs condition-specific top drivers. Takes directories of UQ results.
export-figures Analysis Generate publication-ready PDFs and LaTeX tables from UQ results. Sobol bar charts, heatmaps, cross-strategy comparison figures.
suggest-experiment Experimental Design Identify parameter region with maximum predictive uncertainty. Helps design the next round of experiments to reduce model uncertainty most efficiently.

Remote Execution & Data

CommandTypeDescription
fetch SMS-API Download and parse cd1 analysis TSVs from a completed SMS-API simulation. Works with --simulator-id. Integrates with PrecomputedCache for offline analysis.
show-config Utility Preview the full vEcoli workflow config JSON that `sample` would pass. Useful for debugging variant parameter mutations and analysis options before running.

Setup & Help

CommandTypeDescription
init Setup Guided setup wizard — configure a UQ project interactively. Walks through simData path, parameter selection, observable presets, and output directory.
help Utility Show help for a specific subcommand or the main CLI. Every subcommand also accepts a trailing `help` alias for `--help` (e.g., `uq sample help`).

Typical Usage

# Full two-stage UQ pipeline
uv run uq sample /path/to/simData.cPickle --n-samples 50 --live
uv run uq quantify experiment_id --sim-base-path /path/to/sims
uv run uq report --results-path ./uq_results
# Interactive exploration
uv run uq dashboard --run-mode mo # Marimo GUI
uv run uq tui # Terminal UI
# Remote execution via SMS-API
uv run uq sample /path/to/simData.cPickle --api-url http://sms.example.com --simulator-id 11
uv run uq fetch 48 --api-url http://sms.example.com
