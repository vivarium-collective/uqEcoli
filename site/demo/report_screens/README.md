# Report Screenshots

This directory contains curated screenshots of the UQ report
([uq-report.html](../uq-report.html)) for stakeholder presentations.

| # | File | Subject | How to capture |
|---|------|---------|---------------|
| 1a | `full_page.png` | Full-page browser screenshot of the report | Open `uq-report.html` in a browser. Use full-page screenshot (DevTools > Capture full screenshot). Capture: header, metrics, parameter table, cross-strategy bar chart, "Consistent Rankings" callout. |
| 1b | `sobol_bars.png` | Sobol bar chart close-up — Strategy 1 Population accordion | Open Population accordion. Capture the S_Ti/S_i grouped bar chart with the 6 parameters. Use a snippet tool. |
| 1c | `heatmap.png` | Cell cycle heatmap — Growth-Stratified accordion | Open Growth-Stratified accordion. Capture the viridis heatmap showing stage × parameter grid. |
| 1d | `pce_explorer.png` | Interactive PCE Explorer | Scroll to the Interactive PCE Explorer section. Set a few sliders to non-midpoint values. Capture the sliders, readout cards, and the observable profile chart together. |
| 1e | `provenance.png` | Provenance section | Scroll to the bottom. Capture the provenance info grid showing Git SHAs, dependency versions, and reproducibility info. |
